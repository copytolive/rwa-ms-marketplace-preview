# RWA.ms Desktop — Asset Provenance

Desktop sekarang memakai real HTML/CSS/JS untuk seluruh struktur UI, teks, tombol, navigation, chart SVG, cards, progress bars, tabs, dan interaction hooks.

Tidak ada AI-generated image pada desktop real-code build.

Raster yang dipakai hanya artwork yang berasal langsung dari screenshot referensi milik user: logo, hero photography, category photography, dan product photography. Semua diambil sebagai crop dari `desktop-reference.png`; tidak ada image generation, re-drawing, atau screenshot penuh yang dipakai sebagai layout.

Target viewport validasi: `1672x941`.

File real code utama: `desktop.html`.
File pixel-lock lama dipertahankan hanya sebagai arsip: `desktop-pixel.html`.
