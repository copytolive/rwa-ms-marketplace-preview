# RWA.ms UI Reference Provenance

Reference repository used for UI-pattern study: `vercel/commerce`.

- Clone source: https://github.com/vercel/commerce.git
- Reference commit: `3761e52e60df9c6a316e067dbfd7032e494d3634`
- License: MIT (`license.md` in the reference repository)
- Local reference clone: `/private/tmp/rwa-ui-reference-vercel-commerce` (not bundled into this project)

Patterns studied and adapted to RWA.ms rather than copied as a framework dependency:

- Search result grid and responsive product discovery structure
- Product gallery with selectable images and previous/next navigation
- Product detail split between media and purchase/action context
- Cart/checkout drawer concepts and clear empty/loading states
- Responsive commerce information hierarchy

RWA.ms keeps its existing static HTML/CSS/JS architecture, RWA category taxonomy, visual identity, account UI, and product catalog. No Shopify backend or Vercel Commerce runtime was introduced.
